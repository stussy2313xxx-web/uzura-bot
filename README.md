# うずら BOT v2.1.44.10942

メロジョイUSは、アクセス制限（HTTP 429）が返った場合にショップ指定の時間を待ってから監視を再開します。入店抽選の画面操作では、選択した日付の枠が表示されてから操作します。iPhone総合版、メロジョイ専用版、Androidメロジョイ版に反映しています。

各カートBOTの「モニターディレイ（ms）」で在庫チェックの間隔を指定できます。1000msは1秒です。空欄は従来の自動設定を使います。既存の監視間隔より短くならないように、ストア・監視モードごとの下限を適用します。設定はストアごとに保存します。

VALLADは[新しいカラーミーショップ](https://test.valladstudio.com/)のトップと商品一覧で「うずら BOT · VALLAD」を開き、商品ID・商品URL・型番、または正式な商品名を指定します。サイズ・数量・発売日時（日本時間）を入れて開始し、このタブを開いたままにします。初期時刻は20:00（日本時間）です。発売時刻から最大2分間、初期設定では応答後0.3秒間隔で確認し、一致した在庫があれば商品詳細を開いて指定数量をカートに入れます。商品名は新着一覧に表示された全商品を確認し、色名の「×」と「X」などの表記差を吸収します。型番は新着一覧の先頭12商品を確認します。VALLADパネル内の「実行ログ（日本時間）」で、直近の検索結果・停止理由を確認できます。サイズ展開がない商品はサイズ欄を空欄にします。「うずら BOT · VALLAD」内の「お届け先設定」に保存すると、カートの氏名・住所・連絡先の空欄に自動入力します。カード欄はSafariの自動入力を利用し、注文確定はショップ画面で行います。

Shopify共通対応では、商品詳細ページから開始すると開いている商品を、コレクションから開始するとそのコレクションを監視します。STÜSSY JapanのトップページとNEW ARRIVALSでは新作一覧を監視します。実行ログには配布版の番号と検索先を表示します。カート追加後は商品と数量が指定と一致した場合に購入画面へ進みます。

and STは[公式WEBストア](https://www.dot-st.com/)で「うずら BOT · and ST」を開き、商品名・品番・商品URL、必要に応じて色とサイズを指定します。商品詳細を開いている場合は、商品名欄を空欄にできます。発売日時（日本時間）を予約するか、すぐ実行します。最大2分間確認し、通常販売の商品を1点カートに追加します。「配送先・支払い」から公式の登録画面を開けます。住所は公式マイページ、カードは公式の注文手続きで登録します。「ログを見る」には商品照合、カート追加、停止理由などが日本時間で表示されます。注文手続きは公式カートから進めてください。

- iPhone。SafariのUserscriptsで [iPhone版](uzura-mellojoy-shop.user.js) を使います。導入済みの場合は、Userscriptsの「Updates」から「Check Updates」を実行してください。
- Android。FirefoxのTampermonkeyで [メロジョイ版](uzura-android-mellojoy.user.js) と [ショップ版](uzura-android-shops.user.js) を別々に登録します。VALLADはショップ版に入っています。

MONEY LABの通知は、指定Webhookを保存した端末で動きます。保存済みなら更新後も設定を引き継ぎます。未設定の場合は、BOTを使うブラウザで[通知先の設定ページ](https://github.com/stussy2313xxx-web/uzura-bot?money-lab-notify=setup)を開き、必要に応じて拡張機能にGitHubへのアクセスを許可します。「MONEY LAB 通知先を設定」で新しいWebhook URLを入力すると、指定チャンネルとの一致を確認して端末に保存します。ショップ上には通知ボタンを表示しません。設定確認ではDiscordにメッセージを投稿しません。Androidでメロジョイの通知を使う場合は、メロジョイ版とショップ版を両方有効にします。

実際のカート投入、決済、スマートフォン実機での動作は未検証です。
