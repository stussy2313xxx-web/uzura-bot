# うずら BOT 更新配信

Userscripts向けの更新ファイルです。
初回は管理者から配布された導入用ファイルを使用してください。公開更新ファイルには共通通知先を含めていません。

更新はUserscripts → Updates → Check Updatesから行います。
同じスクリプトとして更新し、保存済みデータを保持してください。削除・再インストールすると通知先などを失う可能性があります。

Mellojoy・Shopify・Supreme・HUMAN MADE・Buffer・Palaceに対応。支払い・注文確定は本人が確認してください。購入者の個人情報はDiscord通知に含めません。
